# RYK Urdu Voice Complaint Routing System

An Urdu voice-based complaint classification and routing system for university services in Rahim Yar Khan, initially covering academic and administrative services, hostel, and transport.

## Project Overview
The system is planned to accept spoken Urdu complaints, convert audio into text, classify each complaint, and route it to the relevant university department for staff review.

## Initial Scope
- University services
- Hostel services
- Transport services

## Planned Technology Stack
- Python
- FastAPI
- Whisper for speech-to-text
- NLP and AI-assisted complaint classification
- React and JavaScript
- SQLite initially, with PostgreSQL as a possible later option
